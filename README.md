# Web Application Security – Module 3

## Project Overview
This project focuses on Web Application Security, demonstrating a Flask-based student portal and practical security testing in a controlled environment.

## Technologies Used
- Python
- Flask
- HTML and CSS
- SQLite

## Features
- Student login page
- Student dashboard
- Student information and marks display
- Web application testing and error handling
- Vulnerability identification and remediation recommendations

## Security Concepts
- HTTP request and response lifecycle
- Authentication and authorization
- Session and cookie security
- OWASP Top 10 vulnerabilities
- Secure coding practices
- Vulnerability analysis and remediation

## Installation and Execution
1. Install Python.
2. Install the required dependencies:

   ```bash
   pip install -r requirements.txt
   ```

3. Start the Flask application:

   ```bash
   python app.py
   ```

4. Open your browser and visit `http://127.0.0.1:5000`.
